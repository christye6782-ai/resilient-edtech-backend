Local Setup Guide

Everything you need to save on one machine to run the prototype now — no internet required at runtime. A connection is needed only once, to install the packages and (optionally) the model.

2

Installed on the machine (not repo files)

Python 3.10+ Required. Runs the backend.
Ollama + llama3.2:3b Optional (~2–3 GB). The on-device model. Without it, the app runs in rule-based basic mode.
Tesseract Optional. Only needed to read photographed / scanned handwritten plans.
3

Run it

pip install -r requirements.txt
cp .env.example .env
sqlite3 app/data/resilient.db < app/schema.sql   # once
uvicorn app.main:app --host 127.0.0.1 --port 5000
# then open http://127.0.0.1:5000

Bare minimum to see it work today: the app/ code + app/data/*.json + the frontend + requirements.txt + .env. Ollama and Tesseract are optional — without the model the app still runs in rule-based mode, and the database file is created from the schema in one command. Nothing here needs the internet at runtime.
